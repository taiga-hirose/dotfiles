# グローバル設定

## コミュニケーション
- 会話は日本語で行う
- コード内のコメントは英語で書く
- 回答は結論を先に、簡潔に。前置きや長い説明は不要

## 作業の進め方
- 複数ファイルにまたがる変更や設計に関わる変更は、着手前に計画を提示して確認を取る
- 小さな修正（typo、1箇所の修正など）は確認なしで進めてよい

## 技術スタック
- 主に素のHTML/CSS/JSとPythonを使う。技術構成はプロジェクトごとに異なるため、各リポジトリの既存の構成・書き方に合わせる
- フレームワークやツールの選定は、プロジェクト内の既存設定（package.json、requirements.txt等）を優先する

## 検証
- 変更後は必ずテストまたはビルドを実行し、結果を報告する
- テストやビルドの仕組みがない場合は、その旨を伝える

## Git
- コミットメッセージは日本語で、変更内容がわかるように書く

## 環境
- 開発環境はMac（コマンドはmacOS前提で書く）
